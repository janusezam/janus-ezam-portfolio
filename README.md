## 🎨 Design System & Philosophy

- **Ink-and-Paper Aesthetic:** Quiet light surface (`#f8fafc`), deep dark slate foundation (`#090d16`), hairline borders, and refined blue accent (`#2563eb` / `#3b82f6`).
- **Complete Theme Parity:** Native `[data-theme="light"]` and `[data-theme="dark"]` support with persistent local storage and anti-flash inline script.
- **Accessible & Doom-Scroll Free:** All modals are portaled directly to `document.body` with locked background scrolling, responsive heights (`max-h-[85vh]`), and keyboard Escape dismissals.
- **Typography:** Space Grotesk for clear editorial headings; JetBrains Mono for small badges, code metrics, and labels.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.18+ or 20+
- npm, pnpm, or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/janusezam/janus-ezam-portfolio.git
   cd janus-ezam-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm run start
```
